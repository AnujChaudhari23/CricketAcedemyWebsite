# Keyword Library

Lookup by category. Use to offer or interpret named styles, not to pick a look by keyword alone: choose from the audience and page job, then use the vocabulary to describe the result precisely.

Contents: 1 Aesthetic styles · 2 Visual depth · 3 Layout · 4 Motion

## 1. Aesthetic styles

| Style | Character | Fits | Watch out |
|---|---|---|---|
| Neo-brutalism | Thick borders, hard offset shadows, flat saturated colour, raw type | Indie tools, creator brands, youth products | Low trust for finance/health |
| Minimalist Elegance | Generous space, restrained palette, refined type | Luxury, portfolios, premium services | Becomes blank without one strong idea |
| Futuristic Cyberpunk | Neon on dark, grids, mono type, HUD details | Gaming, security, dev/AI tools | Glow hurts legibility |
| Organic Editorial | Natural palette, large imagery, expressive type | Food, wellness, nonprofits, travel | Cream + serif + terracotta default trap |
| Acid Graphic | Clashing colour, distorted type, collage | Music, fashion, events | Readability; short pages only |

## 2. Visual depth

| Keyword | What it is | Use when | Cost |
|---|---|---|---|
| Glassmorphism | Translucent blurred layers | Rich content behind the layer | Contrast loss, perf |
| Claymorphism | Soft, inflated rounded 3D forms | Friendly consumer, onboarding | Dated fast |
| Tactile Textures | Grain, paper, fabric, noise | Craft, editorial, warmth | Image weight |
| Liquid Gradients | Fluid mesh colour fields | Brand moments | Blob default; paint cost |
| Chiaroscuro Lighting | Strong light/dark, directional light | Product hero, cinematic | Needs real imagery |

## 3. Layout

| Keyword | Structure | Best for |
|---|---|---|
| Asymmetrical Grid | Uneven columns, intentional tension | Editorial, portfolios |
| Bento Box Grid | Modular tiles of varied size | Feature overviews, dashboards |
| Split-Screen | Two equal-weight halves | Dual audiences, before/after |
| Oversized Typography Hero | Type is the image | Strong brand name; low image budget |
| Infinite Canvas | Pannable/zoomable space | Portfolios, mood boards |

**Mobile re-composition hints:** bento → single column ordered by priority; split-screen → stacked, action first; asymmetry → keep one offset.

## 4. Motion

| Keyword | Pattern | Guardrail |
|---|---|---|
| Micro-interactions | Hover/press feedback, 100–250ms | Must confirm an action |
| Parallax Depth | Layers at different scroll rates | Subtle; disable under reduced motion |
| Kinetic Typography | Type that moves | One moment per viewport |
| Fluid Transitions | Shared-element transitions | Under ~400ms |

## Pairing notes

- One style leads; at most one depth keyword supports; one motion keyword at a time.
- Layout follows content volume: little content → oversized type or split-screen; much content → bento or asymmetrical.
- Strong depth + strong motion + loud style = noise. Remove two.

## Prompt formula (for image/mockup generators only)

Only if the user asks for a mockup-generator prompt.

"[Page type] for [industry/niche], [aesthetic style], featuring [layout type]. Include [visual depth keyword] and [color/lighting keyword]. High-fidelity UI/UX mockup, clean, modern, award-winning design on Behance and Awwwards, crisp vector details, 8k resolution."
